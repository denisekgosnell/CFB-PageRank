This folder holds every regular-season game involving one of the 138 FBS teams of 2026, the AP Top 25, the Coaches Poll, and the CFP committee rankings for the same stretch of the season. The columns are described in `datasets/README.md`. How the data was checked is in `VERIFICATION.md`, right here beside it.

The season was still in progress when the data was collected. The last game in the dataset was played on 2026-11-21. Rivalry week will be week 13.

Data collected at 2026-11-24T19:35:09Z (UTC).
