This folder holds every regular-season game involving one of the 134 FBS teams of 2024, the AP Top 25, the Coaches Poll, and the CFP committee rankings for the same stretch of the season. The columns are described in `datasets/README.md`. How the data was checked is in `VERIFICATION.md`, right here beside it.

The dataset runs through rivalry week, which is week 14.

Data collected at 2026-11-24T19:32:41Z (UTC).
